# Dependency audit and remediation

Audit date: 2026-10-31. Before remediation, `npm audit` reported 2 moderate findings in the root tree and 17 findings in the client tree (16 moderate, 1 high). After remediation, `npm audit --json` and `npm audit --prefix client --json` both reported **0 vulnerabilities**. `npm run build` repeated install/audit and also reported zero vulnerabilities in both trees.

The original client audit listed 17 vulnerable package records. Several records shared one transitive cause, which is why the remediation table groups dependent package names by advisory path. The current lockfile has no audit findings; zero is an observed npm result, not a claim that future or undisclosed vulnerabilities cannot exist. Re-run both audits whenever dependencies change and before deployment.
